# tools/other - 参考资料（不参与编译，不提交 git）

本目录存放开发过程中使用的**参考资料**，与本工程的编译、烧录无关，
因此**不提交到 git 仓库**（体积超过 4GB）。以下为目录清单和原始来源。

| 子目录 | 内容 | 大小 | 原始来源 |
| ---- | ---- | ---- | ---- |
| `uboot/` | 迅为官方 U-Boot 2017 源码包（含内核 3.0、设备树源码、镜像） | 约 4.2GB | 迅为 iTOP-4412 资料盘 / 官方发布 |
| `kernel/` | 内核 3.0 LCD 驱动提取分析（裸机 LCD 参考） | 约 10MB | 迅为内核源码 |
| `schematic/` | 原理图 ASCII/PNG 提取、LVDS 驱动芯片资料 | 约 3MB | 迅为原理图 |
| `manuals/` | 开发板使用手册 PDF、手册文本版 | 约 319MB | 迅为《iTOP-4412 精英版使用手册》 |
| `refs/` | 参考裸机工程、三星/迅为参考代码、旧版驱动 | 约 109MB | 网友开源 + 迅为 |
| `dev/` | 开发过程脚本/日志/MIDI 素材等 | 约 1.5MB | 本项目开发过程产生 |

## 使用说明

1. **普通使用者不需要本目录**：编译、烧录、调试只需要
   `tools\build.ps1`、`tools\burn_sd.ps1`、`tools\toolchain\`、`tools\teraterm\`。
2. 若想补充这些资料，请联系迅为官方获取完整资料包，或参考
   [docs/裸机教程.md](../../docs/裸机教程.md) 中的下载链接。
3. 本目录已被 `.gitignore` 排除，重新克隆 git 仓库不会包含它们，
   这是为了保证仓库体积可控、人人可下载。

> 提醒：`manuals/` 下的 `elite_manual.pdf` 与 `manual_elite.pdf` 内容相同
> （同一手册的两个副本），可自行删除其中一个以节省约 159MB 空间。
